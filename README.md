# Active-Directory-VM-Project
Active Directory home lab using Windows Server in a virtual environment. Installed and configured AD DS, DNS, users, groups, and Group Policy. Implemented password and access policies, tested authentication,
and validated user access. Troubleshot issues via group, DNS, and policy checks. Includes screenshots of setup and configuration.

Active Directory Home Lab
Overview
Academic cybersecurity project demonstrating the implementation and management of a Windows Server Active Directory environment using a virtual machine.

Objective
Build a functional Active Directory environment and configure user access, groups, Group Policy, and supporting network services based on defined requirements.

Environment
Windows Server
Active Directory Domain Services (AD DS)
Group Policy
DNS
VMware / VirtualBox
Windows client environment

Implementation
Built a Windows Server virtual machine environment.
Installed and configured Active Directory Domain Services.
Created and organized users and security groups.
Configured Group Policy settings and password requirements.
Configured and validated DNS functionality.
Tested authentication and user access.
Troubleshot configuration and authentication issues.

Troubleshooting
During testing, authentication issues were investigated by validating user group assignments, DNS configuration, and Group Policy settings. Configuration changes were tested and validated to confirm expected behavior.

Documentation
The screenshots provide visual evidence of the environment and configurations.
